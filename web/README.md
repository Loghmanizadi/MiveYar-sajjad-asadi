# میوه‌یار — نسخه وب اولیه

این پوشه نسخه آغازین وب‌اپ میوه‌یار است؛ رابط فارسی و راست‌چین با طراحی سازگار با گوشی.

## اجرا و انتشار

- فایل `index.html` نقطه ورود برنامه است.
- برای نصب به‌صورت وب‌اپ و کارکرد آفلاین، پروژه باید از یک میزبان HTTPS ارائه شود؛ بازکردن مستقیم فایل HTML برای سرویس‌ورکر کافی نیست.
- `manifest.webmanifest` اطلاعات نصب و `sw.js` کش اولیه فایل‌های برنامه را فراهم می‌کند.

## ذخیره‌سازی و محدودیت‌های نسخه آغازین

- اطلاعات فعلاً در `localStorage` همان مرورگر ذخیره می‌شود؛ پاک‌کردن داده‌های مرورگر ممکن است اطلاعات را از بین ببرد. از بخش پشتیبان‌گیری فایل JSON بگیرید.
- همگام‌سازی ابری، ورود کاربران، پایگاه داده سروری، ثبت چند پرداخت برای یک بدهی، محاسبه کامل FIFO، PDF فارسی و تطبیق کامل کارت‌خوان هنوز پیاده‌سازی نشده‌اند.
- پیش از استفاده مالی واقعی، تمام محاسبات، گزارش‌ها، پشتیبان‌گیری و بازیابی باید با داده‌های آزمایشی بررسی شوند.
- فونت Vazirmatn در این نسخه از Google Fonts بارگیری می‌شود؛ در صورت نبود اینترنت از فونت جایگزین دستگاه استفاده می‌شود.

## مسیر پیشنهادی

1. انتشار روی میزبان HTTPS رایگان که در دسترس کاربر باشد.
2. تست روی گوشی اندروید و نصب از منوی مرورگر «افزودن به صفحه اصلی».
3. تکمیل مدل داده و تست مالی پیش از واردکردن اطلاعات واقعی.
